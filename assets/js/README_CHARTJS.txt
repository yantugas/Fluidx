Cara membuat chart 100% tidak bergantung internet (opsional tapi disarankan):

1. Download file "chart.umd.min.js" dari salah satu link ini (versi 4.4.4):
   - https://cdn.jsdelivr.net/npm/chart.js@4.4.4/dist/chart.umd.min.js
   - https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.4/chart.umd.min.js
   - https://unpkg.com/chart.js@4.4.4/dist/chart.umd.min.js

2. Simpan file tersebut persis di folder ini dengan nama:
   assets/js/chart.umd.min.js

3. Selesai. Halaman admin/persentase_miskonsepsi.php akan otomatis
   memakai file lokal ini lebih dulu (tanpa perlu internet sama sekali)
   sebelum mencoba CDN-CDN di atas sebagai cadangan.
